# 패스오더 · 내 편지 (전달 가이드)

편지를 받은 손님이 건네는 방법을 보고, 건넨 뒤 「편지 건넸어요」를 눌러 기록하는 페이지. 정적 파일만으로 동작하며 GitHub Pages에 그대로 올립니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 가이드 · 기록 시트 · 기록 완료 화면 (한 파일) |
| `config.js` | 기록 전송 주소 · 쿠폰 조건 · 지급 기간 |
| `assets/img/` | 봉투 예시 · 하실 일 2장 · 쿠폰 4장 |
| `../모집랜딩_배포용/apps-script/Code.gs`(두 페이지 공용) | 구글 시트에 신청 · 방문 · 전달 기록을 쌓는 코드 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하도록 하는 빈 파일 |

## 배포

모집 랜딩과 같은 방법입니다. 같은 저장소에 폴더(예: `letter/`)로 두고 `https://<계정>.github.io/<저장소>/letter/` 로 열어도 되고, 저장소를 따로 만들어도 됩니다.

## 링크에 손님 정보 넣기

도착 알림톡 · 리마인드 알림톡 버튼에 모집 때와 **같은 열쇠**와 전달 기한을 붙입니다.

```
https://<계정>.github.io/<저장소>/내편지/?t=열쇠&due=2026-11-19
```

| 파라미터 | 쓰임 |
|---|---|
| `t` | 모집 때 쓴 손님별 열쇠. 매장명 · 닉네임(봉투 예시 이름)을 시트 「모집대상」에서 받아 옴. 같은 기기에서 다시 열면 기록한 상태로 보임 |
| `due` | 전달 기한 (YYYY-MM-DD, 편지 받은 날 + 14일). 「○일 남았어요」 계산에 씀. 없으면 오늘 + 14일 |

열쇠가 없으면 `?store=&nick=` 또는 예시 값(패스카페 · 라떼좋아)으로 보여 줍니다(화면 확인용).

## 기록을 구글 시트로 받기

모집 랜딩과 같은 시트 · 같은 웹 앱(`../모집랜딩_배포용/apps-script/Code.gs`)을 씁니다. 「편지 건넸어요」를 누르면 「전달」 탭에 한 줄이 쌓이고 「모집대상」의 「전달 기록」 열에 Y가 적힙니다.

「전달」 탭 열: 기록시각 · 열쇠 · 회원ID · 매장ID · 매장 · 닉네임 · 건넨 날 · 누구에게 · 신청번호 · 기기 · 열린 앱 · 유입 URL · 참여쿠폰 지급일(운영 입력) · 메모

14일 안 전달 판정은 **기록시각**(버튼을 누른 시각) 기준입니다. 건넨 날은 손님이 고른 참고값입니다.

페이지를 열 때마다 「열람」 탭에도 한 줄이 쌓이고(열람시각 · 열쇠 · 회원 · 매장 · 전달 기한 · 이미 기록함 · 기기 · 열린 앱), 「모집대상」의 「내 편지 열람」 열에 Y가 적힙니다. 도착 · 리마인드 알림톡 뒤 실제로 열어 봤는지 보는 진단 지표용입니다.
