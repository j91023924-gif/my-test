# 패스오더 · 편지 신청 랜딩

손님이 미입점 카페 사장님께 전할 편지를 신청하는 페이지. 정적 파일만으로 동작하며 GitHub Pages에 그대로 올립니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 랜딩 · 신청 · 완료 화면 (한 파일) |
| `config.js` | 신청 내용을 보낼 주소 한 줄. 여기만 바꾸면 됩니다 |
| `assets/img/` | 쿠폰 · 참여 단계 이미지 7장 |
| `apps-script/Code.gs` | 구글 시트에 신청을 쌓는 코드 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하도록 하는 빈 파일 |

## 배포 (GitHub Pages)

1. 이 폴더의 내용을 저장소 루트에 올립니다.
2. 저장소 Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main` / `/ (root)` → Save.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 신청 내용을 구글 시트로 받기

1. 새 구글 스프레드시트를 만듭니다.
2. 확장 프로그램 → Apps Script → 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣고 저장합니다.
3. 배포 → 새 배포 → 유형 「웹 앱」 → 실행 계정 **나**, 액세스 권한 **모든 사용자** → 배포. 처음 한 번 권한 승인이 뜹니다.
4. 나온 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 `config.js`의 `SUBMIT_URL`에 넣고 커밋합니다.
5. Apps Script 편집기에서 `test` 함수를 한 번 실행해 「신청」 시트에 줄이 생기는지 확인합니다.

`SUBMIT_URL`이 비어 있으면 전송 없이 완료 화면만 보여 줍니다(화면 확인용).

## 화면에 들어가는 확정값 (`config.js`)

| 값 | 지금 값 | 쓰이는 곳 |
|---|---|---|
| `SEND_DAYS` | 영업일 3일 | 완료 화면 「신청 마감 뒤 ○ 안에 우편으로」 |
| `PAY_DAYS` | 영업일 3일 | 건넨 날을 알려주신 뒤 참여 쿠폰 지급까지 |

값이 바뀌면 `config.js`만 고칩니다. 「내 편지」 페이지의 `config.js`도 같은 값으로 맞춰 주세요.

시트 탭: 「요약」(신청률 등 자동 계산) · 「모집대상」(메시지 받을 손님, 직접 채움) · 「신청」 · 「방문」(자동 기록). 각 탭의 첫 줄이 열 이름입니다.

## 링크에 손님 정보 넣기 (개인화)

메시지 버튼 링크에는 손님별 **열쇠** 하나만 붙입니다.

```
https://<계정>.github.io/<저장소>/?t=열쇠
```

페이지가 열리면 열쇠로 시트의 「모집대상」 탭을 찾아 매장명 · 닉네임 · 요청 수를 화면에 넣고, 방문 · 신청 기록에 회원ID · 매장ID · 소구 · 경로를 붙입니다. 값을 받아 오는 1~2초 동안 매장명 · 닉네임 자리는 잠깐 가려집니다.

「모집대상」 탭 열 (한 줄 = 메시지 받을 손님 1명)

| 열 | 쓰임 |
|---|---|
| 열쇠 | 링크의 `t` 값. 추측할 수 없는 랜덤 문자열(10자 이상)로 만듭니다. 회원ID를 그대로 쓰면 남의 정보를 볼 수 있어 안 됩니다 |
| 회원ID · 매장ID | 기록용. 화면과 링크에는 나오지 않습니다 |
| 매장명 · 닉네임 | 화면에 들어가는 값. 닉네임은 편지 서명에도 쓰입니다 |
| 요청 수 · 첫 참여 | 화면 문구용 (`Y`/`N`) |
| 소구 · 경로 | 소구 `1`~`4` (1 내 혜택 · 2 특별 대우 · 3 역할의 재미 · 4 사장님 도움), 경로 `call`(전화 주문) · `intro`(앱 주문 요청). 성과 비교용 |
| 발송시각 | 메시지를 보낸 시각 |
| 방문 · 신청화면 도달 · 신청 완료 | 손님이 들어오거나 신청하면 스크립트가 Y를 적습니다. 비워 두세요 |

「요약」 탭의 신청률(판정 지표)은 **신청 완료 ÷ 발송(「모집대상」 줄 수)** 입니다. 메시지를 보낸 사람만 「모집대상」에 넣어 주세요.

열쇠가 없으면 예전 방식(`?store=&nick=&n=&first=`) 또는 예시 값(패스카페 · 라떼좋아)으로 보여 줍니다(화면 확인용). 열쇠가 틀리면 「자주 가는 매장」 · 「손님」으로 보여 줍니다. 첫 화면의 「~하신 ○○님께」 문장은 「모집대상」의 경로(`call` · `intro`)에 맞게 바뀝니다.

## 글꼴

Pretendard 웹폰트를 jsdelivr CDN에서 불러옵니다. 파일을 따로 둘 필요가 없고, CDN이 막힌 환경에서는 기기 기본 고딕으로 보입니다.

## 주소 입력

카카오(다음) 우편번호 서비스를 씁니다. 키 발급이나 도메인 등록 없이 동작합니다.

## 바꿀 때

- 문구 · 쿠폰 금액: `index.html`에서 직접 수정
- 전송 주소: `config.js`
- 동의 문구가 필요 없으면 `id="agree"`가 있는 `<label>` 블록과 `submitForm` 안의 `agree.checked` 검사 한 줄을 지웁니다
- 카카오톡 링크 미리보기 이미지가 필요하면 `<head>`에 `<meta property="og:image" content="https://.../이미지.png">`를 추가합니다 (800×400 권장)
